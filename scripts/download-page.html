Télécharger pour Android

Android 7 ou plus récent, processeur 64 bits (ARM). Au premier téléchargement, autoriser le navigateur à installer des applications ; ensuite, l'app propose elle-même ses mises à jour.

Télécharger pour Linux (AppImage)

64 bits (x86-64), Ubuntu 22.04, Debian 12, Linux Mint 21, Fedora 36 ou plus récents. mpv requis : sudo apt install mpv (ou le paquet mpv de la distribution). Rendre le fichier exécutable (chmod +x) puis le lancer ; la session est gardée dans le trousseau du bureau (GNOME Keyring, KWallet). Ensuite, l'app se met à jour toute seule, si l'AppImage est rangée dans un dossier à soi (par exemple ~/Applications).

Installation sous Windows

  1. Lancer le fichier téléchargé. L'installation se fait pour l'utilisateur courant, sans droits administrateur.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations complémentaires » puis « Exécuter quand même » : l'installeur n'a pas de certificat de signature Windows.
  3. Ensuite, l'app se met à jour toute seule.

Prérequis

  • Windows 10 ou 11, 64 bits.
  • Processeur compatible AVX2.
  • Un abonnement TIDAL valide.
