Download

Lossless music streaming client for Windows, Android and Linux.

Download for Windows

Windows 10 or 11, 64-bit, AVX2-capable processor. The installer needs no administrator rights. If Windows shows "Windows protected your PC", click "More info" then "Run anyway": the installer has no Windows signing certificate. After that, the app updates itself.

Download for Android

Android 7 or newer, 64-bit (ARM) processor. On the first download, allow the browser to install apps; after that, the app offers its own updates.

Download for Linux (AppImage)

64-bit (x86-64): Ubuntu 22.04, Debian 12, Linux Mint 21, Fedora 36 or newer. mpv required: sudo apt install mpv (or your distribution's mpv package). Make the file executable (chmod +x) then run it; the session is kept in the desktop keyring (GNOME Keyring, KWallet). The app updates itself if the AppImage is kept in a folder of your own (for example ~/Applications).

No version is available right now.

Requirements

  • A valid TIDAL subscription.
  • Windows 10 or 11 (64-bit, AVX2), Android 7 or newer (ARM 64-bit), or a recent 64-bit Linux.
